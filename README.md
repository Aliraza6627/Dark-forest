🌲 Dark Forest Survival 🔦

An atmospheric, top-down 2D horror-survival web mini-game built with p5.js.

Navigate through a dangerous, pitch-black forest with only your flashlight beam to guide you. Collect all the glowing fireflies scattered across the map to escape, while evading red-eyed dark creatures stalking you from the fog.

🎮 Game Features

Dynamic Fog of War & Flashlight Mechanics: Real-time lighting system that restricts visibility to your flashlight beam and a small personal radius.

AI Chasing Entities: Shadow monsters that hunt the player across the map.

Collectibles System: Floating fireflies with smooth floating physics.

State Management: Complete game loop including Start Screen, Gameplay, Game Over, and Victory screens.

Zero Installation Required: Runs directly inside any web browser without server setup or build pipelines.

🎯 Gameplay Rules

Objective: Locate and collect all 10 glowing fireflies scattered across the forest floor.

Survival: Avoid coming into contact with the dark creatures. A single touch results in an immediate Game Over.

Lighting: Use your flashlight beam controlled by your mouse to scout path choices and detect monsters early.

🛠️ Installation & Setup

Download/Clone Repository: Save the project folder to your local machine.

Launch: Double-click index.html (or dark_forest_game.html) to open it in your preferred browser (Chrome, Edge, Firefox, or Safari).

Play: Press ENTER or click anywhere on the canvas to begin!
